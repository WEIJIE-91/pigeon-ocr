# Pigeon OCR V1.4 暖藍白視覺版

本版以 V1.3 為基礎，保留原本 JavaScript OCR、分趟校對、整趟刪除、歷史折線圖、localStorage、CSV 與 Google Drive API 邏輯。未變更 localStorage key、OAuth Client ID、函式與資料格式。

## 上傳到 GitHub Pages
請將 **index.html、pigeon-logo.png、favicon.png** 三個檔案一起放到 `WEIJIE-91/pigeon-ocr` 儲存庫根目錄，取代舊的 index.html。請勿刪除目前的 `privacy.html`。

## 功能與測試限制
這次主要是靜態畫面與 CSS 改版，尚未在 iPhone Safari 上完成全流程操作驗證。更新前請匯出 CSV，更新後先檢查 OCR 預覽、分趟校對、歷史成績、Google Drive 備份和還原。

GitHub Pages 提供的是公開網站。Google OAuth 若尚未完成品牌驗證，授權流程可能仍受 Google 政策影響。
